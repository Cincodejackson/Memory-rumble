02 — HARDWARE, DECODED

What does each part do?

A computer is a team. Each part has a job, and the best setup is the one that fits what you want to do.

⌘
PROCESSOR

CPU

The central processing unit runs instructions and coordinates your computer. It matters for everyday responsiveness, productivity, and game logic.

Think: the team captain
▰
GRAPHICS

GPU

The graphics processing unit draws images, video, and 3D worlds. A stronger GPU can help games run at higher detail and resolution.

Think: the visual artist
▥
SHORT-TERM MEMORY

RAM

Random access memory holds the data your apps are using right now. More capacity helps when you keep many tabs or large projects open.

Think: a spacious desk
▤
LONG-TERM STORAGE

SSD

A solid-state drive stores your files and apps even when the computer is off. More space means more room for games, projects, and photos.

Think: the filing cabinet
⌁
